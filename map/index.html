阶段一

临时签证

访客、学生、毕业后工作签证、打工度假、认证雇主工作签证（AEWV）。先核对当前签证的期限与条件（能否工作、能否在境内续签）。

从 AEWV 看起 →
阶段二

居民签证 → 永久居民签证

居民签证（Resident Visa）可以长期居住工作，但通常带旅行条件；满足条件后另行申请永久居民签证（Permanent Resident Visa）。两者不是一回事。

看永久居民签证 →
阶段三

入籍

成为居民后，入籍另有在新西兰实际居住的时间、品行、语言等要求，由内务部（DIA）办理，不归 INZ。

看入籍条件 →

技术类居留：谁来「选」你

进入方式签证怎么进入
INZ 按条件邀请技术移民（SMC）居民签证先递交意向书（EOI），符合要求者获邀（ITA）后递交正式申请；要有认证雇主的工作或工作邀请，并满足三条路径之一。看 SMC →
绿名单 Tier 1直接居留签证（Straight to Residence）职业在绿名单 Tier 1、满足该职业的资格要求与签证条件，即可直接递交，不经 EOI。查绿名单 →
绿名单 Tier 2 与特定行业先工作后居留（Work to Residence；另有护理、交通行业版本）在该职业于新西兰工作满规定时间、工资达到要求后申请。看先工作后居留 →
雇主认证雇主工作签证（AEWV）雇主先取得认证并通过职位核查（Job check），再由员工申请；本身是临时签证，常作为上面几条路径的前一站。
投资与创业主动投资者 Plus、商业投资者、全球影响力签证按投资额、经营或受邀条件进入，门槛差别很大，逐个看签证页。看投资类 →

常见研究路径

学生签证 → 毕业后工作签证 → AEWV 或技术类居留

毕业后工作签证的期限与学历对应；它不等于居留资格，后面的每一步都要重新满足条件。

核毕业后工作签证 →
AEWV → 绿名单 Tier 2 → 先工作后居留 → 永久居民签证

工作时长、工资比例逐个职业不同，见绿名单行业页的官方原文。

核先工作后居留条件 →
伴侣：伴侣工作签证 → 伴侣类居民签证

关系要求（共同生活、真实稳定）与担保人条件照官方原文核对。

核伴侣签证 →
父母：父母居民签证 或 父母长期探亲（Parent Boost）

前者是居留类、名额有限；后者是长期访客签证，不通往居留。

核父母签证 →
